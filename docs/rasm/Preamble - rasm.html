RASM

Documentación del ensamblador RASM

Preámbulo

RASM está diseñado para ser de uso fácil con muchas flexibilidad para desarrollo retro

El ensamblador puede producir binarios con o sin cabeceras (soporta AMSDOS y HOBETA), imágenes de disquetes para Amstrad CPC, archivos Tape CDT (Amstrad y Spectrum), snapshots (Amstrad y Spectrum), cartuchos clásicos o XPR, y ROMs concatenadas o divididas.

Por defecto, nombrará todos los archivos de salida como "rasmoutput" con una extensión para cada tipo de archivo producido. Siéntete libre de usar las muchas opciones de la línea de comandos (como nombrado automático según la fuente).

RASM permite múltiples archivos de salida, puede crear varios binarios con la directiva SAVE, crear/modificar disquetes y hacer un cartuchos al mismo tiempo.

¡RASM realiza cálculos de punto flotante con redondeo correcto!

Si eras usuario de un ensamblador antiguo, es posible que necesites revisar algunos puntos del código fuente, en particular las divisiones por 256 para recuperar el byte alto (usa la función HI para eso). ¡No olvides leer la sección de compatibilidad!

RASM NO distingue entre mayúsculas y minúsculas, RASM NO depende de la indentación, el ensamblador NO es Cobol. Las limitaciones de los ensambladores antiguos eran técnicas, pero ya no.

Nota para los usuarios de Maxam: el símbolo & está reservado para la operación lógica AND. Puede convertir su fuente usando la opción de línea de comandos adecuada.
